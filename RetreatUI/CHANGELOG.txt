RETREATUI v1.0.1
=================

PUBLIC RELEASE — CLASS FRAMEWORK & THEMED INSTALLER
Release date: 2026-07-19
Author: Retreat
Primary supported layout: 1920 x 1080

CLASS STATUS
- Knight of Xoroth — Tank — STABLE
- Venomancer — Fortitude Tank — BETA
- Cultist — Dreadnought Tank — BETA

RELEASE HIGHLIGHTS
- Promoted the latest 1.0.1 development framework into the public release addon.
- Rebuilt the installer around a shared class-aware layout with unique full-page artwork, icons, colors and identity for all three included classes.
- Added the centralized Theme Manager and resource colors based on resource type rather than hardcoded class logic.
- Added shared HUD widgets for counters, forms, cooldown shading, timer text, charge text and dynamic row centering.
- Added beta Venomancer Fortitude support with Exposed Flesh thresholds, Carapace current/max display and Beetle Form / Spider Lord tracking.
- Added beta Cultist Dreadnought support with Mana, Insanity, Total Madness, shield and transformation tracking.
- Added data-driven talent replacements, passive conversions, transformed-form metadata and learned/castable spell filtering.
- Fixed the Check Again dependency refresh error and corrected installer placement across the welcome, install and completion pages.
- Integrated the RetreatUI logo into the installer with transparent edges and subtle class-themed presentation.
- Preserved the complete and stable Knight of Xoroth Tank HUD and integrations.

RETREATUI v1.0.0
=================

FIRST PUBLIC RELEASE
Release date: 2026-07-18

- Added the complete RetreatUI one-click installer for Project Ascension: Conquest of Azeroth.
- Added the first public class module: Knight of Xoroth (Tank).
- Split the package into RetreatUI Core and RetreatUI_Classes for future class expansion.
- Added the shared HUD engine, class registration and loadout detection systems.
- Added the Knight of Xoroth rotation, utility, resource, proc and uptime tracking.
- Added ElvUI, TurboPlates, MobSpells and Details! profile integration.
- Added automatic ElvUI NamePlates deactivation to prevent nameplate conflicts.
- Added safe cleanup of conflicting Blizzard and Ascension UI frames.
- Added matching-version validation between the Core and Classes packages.
- Optimized HUD and NPC cooldown updates for stable gameplay performance.
