RETREATUI v1.0.0
=================

RetreatUI is a modular interface package for Project Ascension: Conquest of Azeroth.

PACKAGE STRUCTURE
- RetreatUI: Core, installer, profiles, integrations, media and the shared HUD engine.
- RetreatUI_Classes: One folder per Conquest of Azeroth class, containing class metadata, spell data and class-specific HUD logic.

CURRENT PUBLIC CLASS MODULE
- Knight of Xoroth
- Supported loadout: Tank
- Primary resolution: 1920 x 1080

REQUIRED ADDONS
- RetreatUI_Classes (bundled in the same release)
- ElvUI
- TurboPlates v1.4.5
- MobSpells v1.3
- Details!

OPTIONAL INTEGRATION
- Deadly Boss Mods

INSTALLATION
1. Close Project Ascension completely.
2. Back up Interface and WTF.
3. Delete old RetreatUI and RetreatUI_Classes addon folders.
4. Extract the release into the Project Ascension game folder.
5. Enable both RetreatUI addon entries and the required addons.
6. Log into a Knight of Xoroth and complete the installer.

Always replace both bundled RetreatUI folders together. Do not mix versions.
RetreatUI does not import, edit, delete or style personal WeakAuras.
