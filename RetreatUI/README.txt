RETREATUI v1.0.10
===================

RetreatUI is a compact Conquest of Azeroth interface package built around ElvUI, TurboPlates, Details! and class-specific combat HUDs.

- Necromancer
- Pyromancer
- Cultist
- Starcaller
- Sun Cleric
- Tinker
- Runemaster
- Primalist
- Reaper
- Venomancer
- Chronomancer
- Bloodmage
- Guardian
- Stormbringer
- Felsworn
- Barbarian
- Witch Doctor
- Witch Hunter
- Knight of Xoroth
- Templar
- Ranger

HUD FEATURES
- Learned-only Main Rotation, Utility, Defensive and racial tracking.
- Active-only proc icons with actionable ability glows.
- Curated player and pet-applied target debuffs above the target frame.
- Dedicated active-state tracking for stances, forms, vows, aspects, oaths, formations, inscriptions and similar class systems.
- Compact class-resource mirrors only when a reliable live source exists.
- Class-specific custom systems for Knight of Xoroth, Bloodmage, Felsworn and Necromancer.
- Necromancer Guardian HUD with active counts, individual health bars, Zombie tracking and a movable L/U lock control.

BUFF MANAGER
- 58 visible buff families across 20 classes.
- One compact button per buff family.
- Automatic normal/Greater selection based on learned spells.
- Normal and Greater auras both count as coverage.
- Red means missing, orange means under five minutes and green means covered.
- Saved class/spec assignments, equivalent-buff detection and automatic migrations.
- Exclusive handling for Bloodmage Offerings and Knight of Xoroth Marks.

INSTALLATION
1. Close Project Ascension completely.
2. Back up the Interface and WTF folders.
3. Install and complete the normal ElvUI setup first.
4. Delete old RetreatUI and RetreatUI_Classes addon folders.
5. Extract both bundled folders into Interface\AddOns.
6. Enable both RetreatUI addon entries and all required addons.
7. Log into a Conquest of Azeroth class and complete its class-specific RetreatUI installer.
8. Repeat once for each class you use. The installer opens automatically; /rui reset is not required.

Always replace both bundled folders together. Do not mix versions.
No TurboPlates addon folder is bundled. Keep the official TurboPlates installation separate.
RetreatUI does not import, edit, delete or style personal WeakAuras.

The release covers a large number of classes and runtime systems. Report missing abilities, incorrect icons, wrong bar placement or class-state issues with a screenshot and the affected class/ability.
