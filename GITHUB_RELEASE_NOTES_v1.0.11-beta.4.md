# RetreatUI v1.0.11-beta.4 — Witch Doctor Voodoo Tracking Test

This prerelease is intended for live Witch Doctor Voodoo testing.

## Test focus

- Hex of Malice / Zalazane's Malice target tracking and expiry warning
- Puppeteer's Threads target timer
- Active Loa / Loa Spirits state and stack display
- Drakkari Barrier cooldown and active duration
- Voodoo Strings, Shadowflare and Voodoo Idol visibility
- Healing Ward and Cleansing Idol utility visibility

Some Ascension aura names can differ from their spellbook names. Please report missing icons, duplicate entries, incorrect names, effects shown on the wrong unit, or trackers that never activate.
