# Naowh UI reference credits

RetreatUI's CoA beta.21 test layout uses the **Naowh UI Project (Retail-like)** as a visual and structural reference for the Ascension: Conquest of Azeroth port.

Original project thread:
- Warmane forum: `https://forum.warmane.com/showthread.php?t=439253`

Original project contributors credited in that thread include:
- **Lunminas / joaodaspica** — WeakAuras project and class UI work.
- **Nethanos** — ElvUI work and UI integration.
- The backport/community contributors referenced by the original project for the supporting addons and media.

The original project explicitly permits alteration and redistribution while asking derivative projects to credit the original work. RetreatUI therefore keeps this attribution alongside the CoA test port.

RetreatUI does not ship the Warmane DBM portion. The CoA port uses Ascension-compatible ElvUI, WeakAuras, Details and TurboPlates integration, while RetreatUI Buff Manager remains a separate optional addon.

RetreatUI addon author metadata remains **Retreat**.
