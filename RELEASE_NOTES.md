# RetreatUI v1.1.7-beta.31 - Tracker Editor WeakAuras Action

This prerelease moves the proven beta.30 native WeakAuras cooldown + buff-duration path into the real Tracker Editor workflow.

## What changed

- Keeps the beta.30 native cooldown + active buff duration generator unchanged.
- Adds a `Build WeakAura` button inside `Configure Tracker`.
- The button saves the tracker settings currently visible in the editor before building the WeakAura import.
- Preserves the tracker HUD group, unit, icon size, glow choice and display/condition settings in RetreatUI profile data.
- Opens WeakAuras' own native import/update dialog for the exact tracker being edited.
- Hides RetreatUI's editor/builder after the WeakAuras import window opens so the native WeakAuras UI has focus.
- `/ruiwatest` remains available only as a legacy proof command; the intended workflow now starts in `/rui tracker`.

## Current native WA scope

beta.31 intentionally supports the proven native tracking path only:

- Cooldown
- Cooldown + Buff duration

Other Tracker Builder types (Proc, Debuff, Stacks, Charges, Resource, Summon/Pet) remain valid RetreatUI profile data but are not generated by the `Build WeakAura` button yet.

## Safety rules

- No `WeakAuras.Add`.
- No custom WeakAuras transmission decoder.
- No custom trigger Lua.
- No automatic acceptance/install.
- WeakAuras 5.21.2 performs its own native import/default validation.
- Building is blocked in combat.

## Test steps

1. Update to beta.31 through the Beta launcher channel.
2. Run `/rui tracker`.
3. Open Apotheosis with `Edit`.
4. Confirm Cooldown + Buff and Duration are selected.
5. Optionally change icon size or another RetreatUI setting.
6. Press `Build WeakAura` directly in Configure Tracker.
7. Confirm the WeakAuras native import window opens for Apotheosis.
8. Import manually.
9. Activate Apotheosis and confirm active buff duration is shown, then falls back to cooldown when the buff expires.
10. Reopen `/rui tracker` and confirm the settings saved by `Build WeakAura` remain stored.
11. Confirm there are no Lua errors.
