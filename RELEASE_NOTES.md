# RetreatUI v1.1.6

RetreatUI 1.1.6 is a focused Conquest of Azeroth stability and layout release.

## TurboPlates

- Keeps caster and mana-user nameplates blue during their normal combat state.
- Adds a distinct orange-red warning state for tanks when they do not own threat.
- Reapplies the threat state after TurboPlates repaints its mana overlay.

## Class HUDs

- Adds a global duplicate guard across every supported class and HUD row.
- Removes duplicate entries such as Unleash Pestilence from the Knight of Xoroth Hellfire HUD.
- Moves the Guardian-only stance tracker upward so it no longer overlaps the resource bar.
- Preserves the shared RetreatUI HUD layout and class-specific placement overrides.

## ElvUI and party frames

- Reduces and realigns party-frame name and health text in the packaged profile.
- Keeps party power bars visible while removing overlapping power text.
- Applies the verified Totem Bar reference position used by the RetreatUI layout.

## Reliability

- Includes the current compatibility, recovery and HUD cooldown-stability safeguards.
- Packages RetreatUI and RetreatUI_Classes together for the Stable channel.
