# RetreatUI v1.0.2 — Conquest of Azeroth Tank HUD Overhaul

RetreatUI v1.0.2 expands the public addon with dedicated class-aware HUD support for four Conquest of Azeroth tank specializations.

## Supported classes

| Class | Tank specialization | Release status |
| --- | --- | --- |
| Knight of Xoroth | Defiance | Stable |
| Bloodmage | Eternal | Early public support |
| Venomancer | Fortitude | Early public support |
| Cultist | Dreadnaught | Early public support |

Knight of Xoroth has received the most extensive gameplay testing. Bloodmage, Venomancer, and Cultist are functional, but have not yet been tested across every talent combination and encounter. Minor tracker, spell-detection, or layout issues may therefore still occur.

## Release goals

- Dedicated class-aware HUDs for all four supported tank specializations.
- Dynamic resource, proc, buff, cooldown, and form tracking.
- Action rows focused on learned and relevant abilities.
- Racials placed in the utility row.
- Class-aware installer artwork and automatic class detection.
- Integrated TurboPlates profile and NPC ability tracking.
- Automatic migration and cleanup of RetreatUI-managed components.
- No preview mode, debug output, temporary patch addons, or required maintenance slash commands.
- Final package contains only `RetreatUI` and `RetreatUI_Classes`.

## Installation target

The final archive will be named:

`RetreatUI_v1.0.2.zip`

Replace both bundled addon folders together. Do not mix files from older development builds.
