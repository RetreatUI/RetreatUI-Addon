# RetreatUI v1.0.1 — Class Framework & Themed Installer

RetreatUI v1.0.1 promotes the latest development framework to the public addon.

## Class status

- **Knight of Xoroth — Tank — Stable**
- **Venomancer — Fortitude Tank — Beta**
- **Cultist — Dreadnought Tank — Beta**

## Highlights

- Added a class-aware themed installer with unique full-page artwork, icons, and colors for all three included classes.
- Added the shared Theme Manager and resource-color framework.
- Added shared HUD widgets and consistent counter, cooldown, timer, and charge presentation.
- Added Venomancer Fortitude beta support.
- Added Cultist Dreadnought beta support.
- Fixed installer placement, dependency refresh, and logo integration issues.
- Preserved the complete and stable Knight of Xoroth Tank module.

## Installation

1. Close Project Ascension completely.
2. Delete the existing `RetreatUI` and `RetreatUI_Classes` folders.
3. Extract the release archive into the Project Ascension game folder.
4. Enable both addons and all required dependencies.
5. Use `/rui install` if the installer does not open automatically.

Always replace both bundled addon folders together. Do not mix versions.
